(4) Para cada uma das questões a seguir, escolha a alternativa correta utilizando a técnica de Prova Direta.
<ul>
a) José está machucado ou não quer jogar. Mas José quer jogar, Logo:<br>
( ) José não está machucado nem quer jogar<br>
( ) José não está machucado e quer jogar<br>
( ) José está machucado e não quer jogar<br>
( ) José está machucado e quer jogar
<p>
b) Ou Márcia voltou ou ficou. Márcia não ficou. Logo:<br>
( ) Márcia não voltou<br>
( ) Márcia não ficou e não voltou<br>
( ) Márcia ficou mas não voltou<br>
( ) Márcia voltou e não ficou<br>
( ) Márcia nem deveria ter ido
<p>
c) Luzia nasceu e brilhou, ou fugiu. Ora, Luzia não fugiu. Logo, Luzia....<br>
( ) nasceu e não brilhou<br>
( ) não nasceu mas brilhou<br>
( ) brilhou, se e só nasceu<br>
( ) nasceu, brilhou e fugiu<br>
( ) nasceu e brilhou
<p>
d) Ou os ensinamentos são ministrados de forma inteligente e lógica, ou a intelectualização constitui-se de um conflito mental. Ora, não houve o conflito mental e isto implica em que:<br>
( ) Os ensinamentos foram ministrados de forma inteligente e lógica<br>
( ) Os ensinamentos foram ministrados de forma não lógica e não inteligente<br>
( ) Os ensinamentos não foram ministrados de forma lógica e inteligente<br>
( ) Os ensinamentos foram ministrados de forma inteligente, mas não lógica
<p>
e) Você estuda mais ou diminui a probabilidade de aprovação. Ora, aumentou a probabilidade de aprovação, logo:<br>
( ) Você estudou menos<br>
( ) Você foi aprovado<br>
( ) Você foi reprovado<br>
( ) Você estudou mais<br>
( ) Você estudou mais, porém reprovou
<p>
f) Se escorre e molha, então escorrega. Não escorregou. Logo:<br>
( ) Escorregou e molhou<br>
( ) Não escorregou e não molhou<br>
( ) Não escorregou ou molhou<br>
( ) Não escorregou ou não molhou<br>
( ) Escorregou, mas não molhou 
</ul>
